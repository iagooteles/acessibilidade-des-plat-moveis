# Urban Accessibility Monitoring Platform ♿📍

An extension project developed for the **Universidade de Fortaleza (UNIFOR)** under the Mobile Platforms Development course.

---

## 📌 Project Overview
Urban centers often present invisible architectural barriers that limit the constitutional right to freedom of movement for people with reduced mobility and the elderly. This mobile application serves as a **collaborative crowdsourcing platform** designed to monitor, evaluate, and map accessibility features in real-time. 

By centralizing user-driven reviews, the platform eliminates information asymmetry, provides route predictability, and fosters social equity, allowing users to navigate public and private urban spaces safely and autonomously.

---

## 🚀 Core Features
The platform is built around key functional requirements to ensure a seamless and impactful user experience:

* **Interactive Map & Geolocation (RF05):** View nearby registered locations and check their accessibility markers on a live map interface in real-time.
* **Collaborative Evaluations (RF03 & RF04):** Review locations based on standard structural criteria using checklists and ratings (e.g., sidewalk quality, presence of access ramps, and tactile paving).
* **Location Management (RF01 & RF02):** Easily register new locations, public pathways, or establishments with custom details.
* **Community Feedback Loop (RF08 & RF09):** Read and post detailed comments, sharing practical insights with other community members.

---

## 🛠️ Tech Stack & Methodology
* **Frontend:** React Native (Expo Framework)
* **Design Standards:** WCAG-aligned Accessibility UI Design (Contrast Adjustments & Screen Reader Compatibility)
* **Project Management:** **Scrum Framework** (Iterative Development via 2-week Sprints aimed at continuous feedback and continuous integration)
